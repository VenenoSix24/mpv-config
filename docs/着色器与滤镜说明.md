# 着色器 / VF 滤镜 / onnx 模型说明

> 环境：AMD 6750 GRE 12G（Navi 22）· 2560×1440 · d3d11 后端 · AFMF（amf_frc）默认开启
> 快捷键与菜单项定义见 `input_uosc.conf`（右键 uosc 菜单）与 `menu.conf`（Ctrl+右键原生菜单）。

## 一、着色器（shaders/，GLSL，渲染阶段，与 AFMF 无冲突，随开随关）

### LUMA（亮度平面放大/重建，主放大，互斥）

| 菜单名 | 文件 | 用途 |
|---|---|---|
| Ani4Kv2 | Ani/Ani4Kv2_ArtCNN_C4F32_i2_dx | ArtCNN 架构动画 x2，720p 番日常主力（d3d11 特调） |
| AniSD | Ani/AniSD_ArtCNN_C4F32_i4_dx | 低清/老动画向的 ArtCNN x2 |
| FSRCNNX | FSRCNNX/FSRCNNX_x2_16_0_4_1 | 经典通用 x2，真人可用 |
| NNEDI3 | EDI/nnedi3_nns64_win8x4 | 传统插值，自然观感，无 AI 味 |
| ArtCNN_C4F32 | ArtCNN/ArtCNN_C4F32 | ArtCNN 原版最高档；实测 luma 榜第一（与 Ani4Kv2 同源，二选一） |
| FSRCNNX_56 | FSRCNNX/FSRCNNX_x2_56_16_4_1 | FSRCNNX 最高质量档，真人主力 |
| FSRCNNX_fastv2 | FSRCNNX/FSRCNNX_x2_2_16_0_4_1_v1_fastv2 | 轻量，适合游戏视频/电子游戏画面 |
| SSimSuperRes RT | SSim/SSimSuperRes_RT | 结构重建放大，走 mpv 内部缩放，不与其他 LUMA 超分混用 |

| ArtCNN_Chroma | ArtCNN/ArtCNN_Legacy_C4F32_Chroma | 色度还原实测第一，动画向 |

### POSTKERNEL / SCALED（收尾处理）

| 菜单名 | 文件 | 用途 |
|---|---|---|
| QCOM_锐化 | QCOM/QCOM_SGEDS_ms_RT | mpv.conf 默认挂载的缩放锐化 |

另有 mpv360.glsl，属于全景视频工具（配合 mpv360.lua），不参与画质链。

## 二、VF 滤镜（vs/，VapourSynth，会退回软解管线，负载大）

| 入口 | 脚本 | 模型/算法 | 用途 |
|---|---|---|---|
| `!` | MEMC_MVT_LQ.vpy | mvtools 光流 | 补帧（开销低） |
| `@` | MEMC_RIFE_DML.vpy | RIFE v4.6（DirectML） | AI 补帧 |
| SHARP | MEMC_DRBA_DML.vpy | DRBA（DirectML） | AI 补帧 |
| `^` | MIX_UAI_DML.vpy | AnimeJaNai V2L1 | AI 超分（可改 Model 行换模型） |
| `a` | MIX_UAI_DML.vpy | 同上 | AI 超分 + format=d3d11 + AFMF 串接 |
| 菜单：AI超分(动画) | UAI_DML_Anime.vpy | AnimeJaNai V2L1 | 动画 |
| 菜单：AI超分(真人) | UAI_DML_Photo.vpy | hongyuanyu_span_ch48 | 真人 |
| 菜单：AI超分(游戏) | UAI_DML_Game.vpy | QCOM QuickSRNet Medium | 游戏视频 |
| 菜单：开关 AFMF | — | amf_frc（AMD 硬件补帧） | 临时开/关全局 AFMF |

- RIFE/DRBA/UAI 的 NV（TensorRT）预设已从菜单移除，vpy 文件保留。
- `format=d3d11,amf_frc` 必须跟在 vapoursynth 之后且一次性写入滤镜链；先开 VS 预设再单独开 AFMF 会报 "FRC init failed" 并被自动禁用。

## 四、组合推荐

### 动画（720p 番 → 2K）
- 日常：Ctrl+1（Ani4Kv2）+ ArtCNN_Chroma，可选叠 Ctrl+0 锐化
- 发烧：菜单「AI超分(动画)+AFMF」（AnimeJaNai V2L1 onnx）
- 老番/糊源：A4K_抗振铃 → A4K_重建VL → A4K_放大VL 三件套（或 Ctrl+2 AniSD）

### 真人（电影/剧集/演唱会）
- 着色器路线（推荐）：FSRCNNX_56 + KrigBilateral + Ctrl+0
- onnx 路线：菜单「AI超分(真人)+AFMF」（hongyuanyu span），帧率不满意就退回着色器路线
- 低负载：Ctrl+3（FSRCNNX 16 档）或 Ctrl+4（NNEDI3）

### 游戏视频/实况
- 着色器：FSRCNNX_fastv2 + Ctrl+0
- onnx：菜单「AI超分(游戏)+AFMF」（QCOM QuickSRNet，最轻）

### 通用规则
1. 主放大一次一个：LUMA 区互斥，onnx 预设与 LUMA 区互斥。
2. 修复/色度/锐化可叠加在主放大之后，总数控制在 2~3 件。
3. SSimSuperRes 单独使用（配套 mpv 内部缩放），不与任何 LUMA 超分混叠。
4. 4K 源关掉全部放大；低码率网络源优先用 Restore 类修复而不是强力放大。
5. 补帧：日常 AFMF 全局默认；RIFE/mvtools 仅作对照实验。
6. 验证：`I` 看 fps/丢帧，`Ctrl+i` 看输出分辨率是否高于源。
