# 本地自定义清单（对比上游 lite）

日期：2026-09-05
基线：hooke007/mpv_PlayKit `lite` 分支 `e92b17d`（即 mpv-lazy-20260510 发行版）
对比对象：C:\Softwares\mpv-lazy\portable_config

结论：安装包的配置与上游 lite 最新版同源，以下差异即本地全部自定义内容。

## 修改的文件

### mpv.conf

| 位置 | 上游 | 本地 | 说明 |
|------|------|------|------|
| 基础/视频输出 | `#gpu-context = winvk` | `gpu-context = d3d11` | 指定 D3D11 渲染上下文 |
| 基础/硬件解码 | `hwdec = auto-copy` | `hwdec = d3d11va` | 换用 d3d11va 硬解 |
| 新增（hwdec 之后） | 无 | `vf-append = amf_frc=profile=auto:indicator=yes` | AMD AFMF 帧生成 |
| 新增 | 无 | `d3d11-adapter` / `vulkan-device` = "AMD Radeon RX 6750 GRE 12GB" | 绑定独显 |
| 文件末尾 | 无 | `cookies=yes`、`cookies-file`、`ytdl-raw-options-append=cookies` | B站 cookie，供 yt-dlp 播放网页视频用（指向 Downloads 下的 cookies txt） |

### input_uosc.conf

| 键 | 上游 | 本地 | 说明 |
|----|------|------|------|
| `r` | 未绑定 | `cycle-values video-rotate 0 90 180 270` | 视频循环旋转（进入uosc菜单） |
| `MBTN_LEFT` | `ignore` | `cycle pause` | 左键单击暂停/播放 |
| `WHEEL_UP` / `WHEEL_DOWN` | 注释（未启用） | 启用 | 滚轮调音量并刷新 uosc 音量条 |

## 新增的文件（上游没有）

- `scripts/mpv360.lua` + `script-opts/mpv360.conf` + `shaders/mpv360.glsl` — mpv360 功能组
- `danmaku-history.json`、`saved-props.json` — 运行时产生的状态文件，非手动修改

## 与上游一致、未改动的部分

profiles.conf、script-opts.conf、menu.conf、fonts、shaders（除 mpv360.glsl）、vs 全部与上游一致。

## 备注

- 上游 lite 仓库里 `scripts/uosc`、`scripts/thumb_engine`、`input_plus.lua`、`save_global_props.lua` 是空占位文件，实际脚本源码只随发行 zip 分发，无法用 git 仓库直接比对。已将上游 main 分支的 vendored uosc 源码与本地比对，差异均属于 hooke007 的打包补丁与版本滞后（本地 uosc 5.12.1 @ commit 99510d5），未见本地手改痕迹。
- 上游仓库克隆保存在 `upstream/mpv_PlayKit_git`（不纳入本仓库，见 .gitignore），以后升级时先 `git fetch` 更新它再做对比。
